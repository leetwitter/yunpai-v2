## 4. 关键设计决策（详见书一/书二，偏差见 docs/05）

1. **唯一执行路径**：无第二套执行循环；Gate 用 interrupt()/Command(resume)，挂起前 side-effect 落库 waiting_human（GET /runs/{id} 与 resume 依赖此镜像）。
2. **装配单源**：free 与 workflow 共用 bridge_payload（旧 free 死点 `ingest_m5_planning_snapshot` 已从根上修复）。
3. **路由目录只含已绑定工具**（CatalogView）——LLM 不可能再提案 `run_mrp_procurement_plan` 这类不存在/废弃名。
4. **审查规则数据化**：RULES 表 + manifest review_gate 默认门；任何置信度不得自动 approve（test_no_auto_approve 锁定）。
5. **绑定四态**：30 本地 + 53 HTTP + 1 沙箱（import_m4 fixture）+ 35 不绑（含 2 个故意不绑、2 个编排内部反馈面）。
